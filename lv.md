Перед уменьшением LV убедитесь, что **суммарный объем оставшихся 3 PV** будет больше или равен новому размеру логического тома. Если после удаления 2 дисков оставшегося места не хватит, `lvreduce` или последующая работа с томом завершатся ошибкой.

1. Отмонтируйте файловую систему:
    
    ```
    sudo umount /dev/<vg_name>/<lv_name>
    ```
    
2. Уменьшите размер файловой системы (для ext4):
    
    ```
    sudo resize2fs /dev/<vg_name>/<lv_name> <new_fs_size>
    ```
    
    _Пример: `sudo resize2fs /dev/vg0/lv0 3T`_
    
3. Уменьшите размер LV до того же или чуть большего значения:
    
    ```
    sudo lvreduce -L <new_lv_size> /dev/<vg_name>/<lv_name>
    ```
    
    _Пример: `sudo lvreduce -L 3T /dev/vg0/lv0`_
    
4. Проверьте целостность ФС и смонтируйте обратно:
    
    ```
    sudo e2fsck -f /dev/<vg_name>/<lv_name>
    sudo mount /dev/<vg_name>/<lv_name> <mount_point>
    ```
    
    _Верификация:_ команда `df -h` должна показать уменьшенный размер тома, а данные должны быть доступны.
    

### Шаг 2. Проверка занятости PV и освобождение данных (`pvmove`)

Чтобы узнать, хранят ли те 2 диска, которые вы хотите удалить, какие-либо данные, используйте команду `pvdisplay` с флагом `-m` (маппинг экстентов) или `pvs`:

```
sudo pvdisplay -m /dev/sdX
```

_(где `/dev/sdX` — один из удаляемых PV)._

- Обратите внимание на поле **Allocated PE** (или секцию `Physical Segments`). Если там указано ненулевое количество выделенных блоков, значит, на диске есть данные. Если `Allocated PE = 0`, диск полностью пуст, и вы можете сразу переходить к Шагу 3.
    

Если на диске **есть данные**, их необходимо перенести на оставшиеся в VG диски с помощью утилиты `pvmove`. Она работает "на лету" даже при смонтированной ФС:

```
sudo pvmove /dev/sdX
```

- _Верификация:_ Повторите `sudo pvdisplay -m /dev/sdX`. Убедитесь, что поле `Allocated PE` стало равным `0`. Это значит, что все данные с этого физического диска успешно перемещены на другие PV в составе вашей VG.
    

Повторите эту процедуру для второго удаляемого диска.

### Шаг 3. Удаление PV из Volume Group (`vgreduce`)

Когда оба целевых диска полностью освобождены от данных (на них нет `Allocated PE`), удалите их из Volume Group:

```
sudo vgreduce <vg_name> /dev/sdX /dev/sdY
```

- _Верификация:_ Выполните `sudo vgdisplay <vg_name>` или `sudo pvs`. В выводе должно остаться ровно 3 PV, а общая емкость VG (`VG Size`) должна уменьшиться на объем удаленных дисков.
    

### Шаг 4. Очистка метаданных LVM (опционально)

Если вы планируете физически извлечь эти диски, отдать под другие задачи или занулить, удалите с них служебные метки LVM:

```
sudo pvremove /dev/sdX /dev/sdY
```

- _Верификация:_ Выполнение `sudo pvs` больше не должно отображать эти устройства в списке инициализированных физических томов.
